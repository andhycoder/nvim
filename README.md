# Neovim
---

konfigurasi neovim yang saya gunakan saat ini. menggunakan neovim 0.12+.

## Instalasi

```bash
git clone https://github.com/andhycoder/nvim-config.git /path/to/nvim
```

## overview

neovim adalah sebuah text editor berbasis terminal dan merupakan varian dari vim.
Salah satu yang membuat neovim menarik adalah neovim memgandalkan keyboard mulai dari navigasi dan shortcut.

## list plugin

config ini memggunakan package manager native `vim.pack` dan memggunakan plugin di antaranya

- [blink.cmp](https://github.com/saghen/blink.cmp)
- [friendly-snippets](https://github.com/rafamadriz/friendly-snippets)
- [conform.nvim](https://github.com/stevearc/conform.nvim)
- [mini.nvim](https://github.com/echasnovski/mini.nvim)
- [nvim-dap](https://github.com/mfussenegger/nvim-dap)

- [nvim-nio](https://github.com/nvim-neotest/nvim-nio)
